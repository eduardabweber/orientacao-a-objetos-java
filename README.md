# Orientação a Objetos em Java

Repositório destinado ao armazenamento de exercícios e atividades desenvolvidos durante a disciplina de Orientação a Objetos em Java, no curso de Tecnologia em Análise e Desenvolvimento de Sistemas da Universidade Tecnológica Federal do Paraná (UTFPR).

## Tecnologias

- Java
- Eclipse IDE
- Git e GitHub

## Conteúdo

- Classes e objetos
- Instanciação
- Encapsulamento 
- Construtores
- Métodos
- Estruturas condicionais 
- Entrada e saída de dados
- Relacionamento entre classes

## Objetivo

Praticar e consolidar os conceitos de programação orientada a objetos por meio do desenvolvimento de exercícios em Java.
